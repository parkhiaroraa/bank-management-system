# Bank Management System in C++

A C++ Console Application that manages bank accounts, including account creation, balance inquiry, money deposits, withdrawals, and account searching.

---

## 🛠️ Features
- **Account Creation:** Create a new bank account with user details and initial balance.
- **Deposit & Withdraw:** Seamlessly add or withdraw funds with real-time balance checks.
- **Account Search:** Quick lookup by account number.
- **Display Accounts:** View all registered accounts and current balances.
